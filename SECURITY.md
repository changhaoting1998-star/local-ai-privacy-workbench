# Security Policy

Security fixes currently target the latest commit on `main`.

Report vulnerabilities through GitHub's private security advisory flow. Do not include real personal data, credentials, provider tokens, private documents, databases, or sensitive screenshots in a public issue.

Use synthetic fixtures whenever possible and include the affected commit, operating system, expected behavior, and smallest safe reproduction.

This project is a tested local prototype. It is not a certified DLP product, hardened multi-user service, or guarantee that every sensitive value will be detected.
